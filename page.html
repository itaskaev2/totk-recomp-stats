Отработанный тред
Свой тред или чужой, где есть хотя бы один мой комментарий.
Закрыт после комментария
Чужой тред закрыт или влит позже моего первого комментария. Это совпадение по времени, а не доказательство, что закрыли именно из-за комментария.
Принятый PR
Влит через GitHub или влит вручную: мейнтейнер перенёс код своим merge-коммитом с номером PR (так было с #89, #489, #701, #729), а сам PR закрыл.
Токены и сессии
Логи Claude Code четырёх сессий проекта (основная, её форк и два продолжения) с их субагентами. Ответы с одним id считаются один раз, поэтому общая история форков не удваивается. Сессии Hermes и другие проекты не входят.
Время
Сумма промежутков между событиями основной ветки сессий, паузы длиннее 10 минут отброшены. Субагенты, работавшие параллельно, время не добавляют.
